## Problem Description

Given a 0-indexed n x n integer matrix grid , return the number of pairs (r i , c j ) such that row r i and column c j are equal . A row and column pair is considered equal if they contain the same elements in the same order (i.e., an equal array).

---

## Examples

```
Input: [[3,2,1],[1,7,6],[2,7,7]]
Output: [[3,1,2,2],[1,4,4,5],[2,4,2,2],[2,4,2,2]]
```

---

## Constraints

- n == grid.length == grid[i].length 1 <= n <= 200 1 <= grid[i][j] <= 10 5
