# [4006. Count Valid Prefixes](https://leetcode.com/problems/Count-Valid-Prefixes/)

![Difficulty](https://img.shields.io/badge/Difficulty-Easy-green?style=flat-square)

---

## Problem Description

You are given a binary string s . A prefix of s is considered valid if its characters can be rearranged to form an alternating string. Return the number of valid prefixes of s . A binary string is a string consisting only of '0' and '1' . A prefix of a string is a substring that starts from the beginning of the string and extends to any point within it. A substring is a contiguous non-empty sequence of characters within a string. A string is considered alternating if no two adjacent characters are equal.

---

## Examples

```
Input: "00101"
Output: "101"
```

---

## Constraints

- 1 <= s.length <= 100 s consists only of '0' and '1' .
