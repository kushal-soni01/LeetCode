## Problem Description

You are given a positive integer n . Return the maximum product of any two digits in n . Note: You may use the same digit twice if it appears more than once in n .

---

## Examples

```
Input: 31
Output: 22
```

---

## Constraints

- 10 <= n <= 10 9
