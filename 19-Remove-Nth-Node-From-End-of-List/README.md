## Problem Description

Given the head of a linked list, remove the n th node from the end of the list and return its head.

---

## Examples

```
Input: [1,2,3,4,5]
Output: 2
```

```
Input: [1]
Output: 1
```

```
Input: [1,2]
Output: 1
```

---

## Constraints

- The number of nodes in the list is sz . 1 <= sz <= 30 0 <= Node.val <= 100 1 <= n <= sz
