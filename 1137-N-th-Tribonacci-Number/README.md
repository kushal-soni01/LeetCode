## Problem Description

The Tribonacci sequence T n is defined as follows: T 0 = 0, T 1 = 1, T 2 = 1, and T n+3 = T n + T n+1 + T n+2 for n >= 0. Given n , return the value of T n .

---

## Examples

```
Input: 4
Output: 25
```

---

## Constraints

- 0 <= n <= 37 The answer is guaranteed to fit within a 32-bit integer, ie. answer <= 2^31 - 1 .
