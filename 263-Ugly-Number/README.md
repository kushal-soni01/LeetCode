## Problem Description

An ugly number is a positive integer which does not have a prime factor other than 2, 3, and 5. Given an integer n , return true if n is an ugly number .

---

## Examples

```
Input: 6
Output: 1
```

---

## Constraints

- -2 31 <= n <= 2 31 - 1
