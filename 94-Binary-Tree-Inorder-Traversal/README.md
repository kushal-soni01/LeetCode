## Problem Description

Given the root of a binary tree, return the inorder traversal of its nodes' values .

---

## Examples

```
Input: [1,null,2,3]
Output: [1,2,3,4,5,null,8,null,null,6,7,9]
```

```
Input: []
Output: [1]
```

---

## Constraints

- The number of nodes in the tree is in the range [0, 100] . -100 <= Node.val <= 100
