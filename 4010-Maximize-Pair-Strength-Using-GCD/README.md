# [4010. Maximize Pair Strength Using GCD](https://leetcode.com/problems/Maximize-Pair-Strength-Using-GCD/)

![Difficulty](https://img.shields.io/badge/Difficulty-Easy-green?style=flat-square)

---

## Problem Description

You are given an integer array nums . Choose exactly one pair of distinct indices i and j . The strength of the pair is defined as (nums[i] * nums[j]) / gcd(nums[i], nums[j]) 2 . Return the maximum strength over all possible pairs.

---

## Examples

```
Input: [2,3,5]
Output: [4,6,8]
```

---

## Constraints

- 2 <= nums.length <= 2000 1 <= nums[i] <= 10 5
