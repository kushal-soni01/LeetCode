## Problem Description

You are given a palindromic string s . Return the lexicographically smallest palindromic permutation of s .

---

## Examples

```
Input: "z"
Output: "babab"
```

---

## Constraints

- 1 <= s.length <= 10 5 s consists of lowercase English letters. s is guaranteed to be palindromic.
