# [3978. Unique Middle Element](https://leetcode.com/problems/Unique-Middle-Element/)

![Difficulty](https://img.shields.io/badge/Difficulty-Easy-green?style=flat-square)

---

## Problem Description

You are given an integer array nums of odd length n . Return true if the middle element of nums appears exactly once in the array. Otherwise return false .

---

## Examples

```
Input: [1,2,3]
Output: [1,2,2]
```

---

## Constraints

- 1 <= n == nums.length <= 100 n is odd. 1 <= nums[i] <= 100
