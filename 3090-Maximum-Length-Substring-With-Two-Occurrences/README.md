## Problem Description

Given a string s , return the maximum length of a substring such that it contains at most two occurrences of each character.

---

## Examples

```
Input: "bcbbbcba"
Output: "aaaa"
```

---

## Constraints

- 2 <= s.length <= 100 s consists only of lowercase English letters.
