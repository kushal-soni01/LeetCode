## Problem Description

You are given an integer array nums of length n . Construct an array prefixGcd where for each index i : Let mx i = max(nums[0], nums[1], ..., nums[i]) . prefixGcd[i] = gcd(nums[i], mx i ) . After constructing prefixGcd : Sort prefixGcd in non-decreasing order. Form pairs by taking the smallest unpaired element and the largest unpaired element. Repeat this process until no more pairs can be formed. For each formed pair, compute the gcd of the two elements. If n is odd, the middle element in the prefixGcd array remains unpaired and should be ignored. Return an integer denoting the sum of the GCD values of all formed pairs. The term gcd(a, b) denotes the greatest common divisor of a and b .
