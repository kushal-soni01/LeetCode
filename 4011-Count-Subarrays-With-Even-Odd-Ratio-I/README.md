# [4011. Count Subarrays With Even Odd Ratio I](https://leetcode.com/problems/Count-Subarrays-With-Even-Odd-Ratio-I/)

![Difficulty](https://img.shields.io/badge/Difficulty-Medium-yellow?style=flat-square)

---

## Problem Description

You are given an integer array nums and two integers a and b . For a subarray , let: x be the number of even elements. y be the number of odd elements. The ratio of even to odd elements in a subarray is defined as x / y , where ratios are compared by their exact rational values. A subarray is considered valid if: y > 0 , and x / y <= a / b . Return the number of valid subarrays in nums .
