## Problem Description

Given an array of positive integers arr , return the sum of all possible odd-length subarrays of arr . A subarray is a contiguous subsequence of the array.

---

## Examples

```
Input: [1,4,2,5,3]
Output: [1,2]
```

---

## Constraints

- 1 <= arr.length <= 100 1 <= arr[i] <= 1000
