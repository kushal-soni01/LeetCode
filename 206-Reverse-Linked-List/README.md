## Problem Description

Given the head of a singly linked list, reverse the list, and return the reversed list .

---

## Examples

```
Input: [1,2,3,4,5]
Output: [1,2]
```

---

## Constraints

- The number of nodes in the list is the range [0, 5000] . -5000 <= Node.val <= 5000
