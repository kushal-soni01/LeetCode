## Problem Description

Given a string s , find the length of the longest substring without duplicate characters.

---

## Examples

```
Input: "abcabcbb"
Output: "bbbbb"
```

---

## Constraints

- 0 <= s.length <= 10 5 s consists of English letters, digits, symbols and spaces.
